# Identidade Servlog

Diretório reservado aos arquivos oficiais da marca utilizados pela interface.

O arquivo `Logo facilities.png` foi disponibilizado pelo responsável e integrado ao cabeçalho por `components/servlog-brand.tsx` usando Next Image.

Original preservado: PNG com alpha, 1815 × 871 pixels. A interface mantém essa proporção e usa nome acessível Servlog, largura de 160px no mobile e 192px a partir de 640px. Um suporte branco melhora a leitura do arquivo original sobre o tema escuro; nenhuma alteração foi feita na imagem.

Cores de referência documentadas em UI_UX.md:

- Azul escuro: `#0a468f`.
- Azul de destaque: `#16a8e6`.
- Azul profundo: `#083568`.

Os tokens CSS `--brand-primary`, `--brand-highlight` e `--brand-deep` centralizam essas referências. Arquivos em public são públicos mesmo quando a demonstração está bloqueada; não incluir dados ou documentos internos neste diretório.
